MSC MANSION SPACE CREATIVE STUDIO
=================================

FILES
-----
index.html  = public website
style.css   = website styling
script.js   = website interactions + estimate quotation
admin.html  = private owner panel
admin.js    = owner panel controls
assets/     = logo and website assets

OWNER PANEL
-----------
1. Open admin.html in the same browser/device where you want to manage the site.
2. Password: MSC-ADMIN-2026
3. You can edit hero/about text, add project photos, replace photos, change project title/location/category, and delete projects.
4. Click Save. Then open index.html in the same browser to preview changes.

IMPORTANT
---------
This version is a browser-only owner panel. Changes are stored in that browser's local storage. They are NOT automatically shared with visitors on other devices.

For a real live website CMS where you can securely log in from anywhere and changes/images appear for every visitor, connect the owner panel to a backend/database and image storage such as Supabase or Firebase with real authentication.

Before publishing, change ADMIN_PASSWORD in admin.js.
