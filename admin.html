Important

This owner panel works without a server and stores your edits/images in this browser. That means visitors on other phones/computers will not see the changes. For a real private CMS where you can manage the live website from anywhere, connect this panel to a database + image storage (for example Supabase/Firebase) and real authentication.

Tip: after editing, open the website in the same browser to preview your changes.
